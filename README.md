# Ryan Wynn Portfolio

Astro structural motion prototype for the five-scene portfolio experience defined in
`docs/portfolio-brief.md`.

## Requirements

- Node.js 22.22.3 or newer
- npm

## Setup

```sh
npm install
```

Start and manage the repository's background development server:

```sh
npm run astro -- dev --background
npm run astro -- dev status
npm run astro -- dev logs
npm run astro -- dev stop
```

## Verification

```sh
npm run check
npm run lint
npm run format:check
npm run build
```
